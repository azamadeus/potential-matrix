# Матрица Потенциала и Зрелости

Интерактивный веб-тест личностного потенциала: ведущие архетипы (ТОП-3 из 12), индекс зрелости каждого таланта и тип самооценки.

**Стек:** Vite, React 19, TypeScript, Tailwind CSS 4, примитивы в стиле shadcn/ui, Framer Motion, Vitest. Шрифты Unbounded и Onest собраны в приложение через `@fontsource`, внешние CDN не нужны. Сервера нет: всё считается в браузере.

## Запуск

```bash
npm install
npm run dev        # http://localhost:8080
npm test           # юнит-тесты алгоритма
npm run lint
npm run build      # статическая сборка в dist/
npm run preview
```

## Lovable

Проект совместим с Lovable (Vite + React + TypeScript + Tailwind, алиас `@/` указывает на `src/`, dev-сервер на порту 8080).
Подключить можно двумя способами:

1. **Через GitHub.** Если в вашей версии Lovable есть импорт существующего репозитория, выберите этот репозиторий и ветку `main`.
2. **Через новый проект.** Создайте проект в Lovable, подключите его к GitHub (Lovable создаст свой репозиторий), затем перенесите туда содержимое этого репозитория одним коммитом. Lovable подхватит изменения автоматически.

Сборка статическая (`dist/`), поэтому её можно выложить и на любой хостинг: Lovable, Vercel, Netlify, GitHub Pages.

## Страницы

- `/` лендинг: о тесте, 12 карт колоды, пример результата, тарифы «Для себя» и «Для компании», частые вопросы.
- `/test` сам тест и результаты.

Для хостингов без поддержки SPA-маршрутов добавлены `public/_redirects` (Netlify) и `vercel.json` (Vercel): прямой заход на `/test` отдаёт приложение.

## Цена, скидки, АВР и оплата

- Настройки в `src/config/site.ts`: цена 4 990 ₸ за человека, скидки 10% от 3 до 10 человек и 15% от 11 до 20, максимум 20 человек в калькуляторе, почта для заявок we@mentorhub.one. Расчёт и проверки БИН и почты в `src/lib/pricing.ts` (покрыты тестами).
- Калькулятор на лендинге считает цену за человека, итог и экономию. Галочка «Нужен АВР» открывает поля «Компания», «БИН», «Почта для АВР».
- Пока нет сервера, заявка на АВР открывает почту покупателя с готовым письмом на we@mentorhub.one (количество, сумма, скидка, реквизиты). Группы больше 20 человек пишут туда же.
- Оплата подключается в одном месте: `startCheckout(order)` в `src/lib/checkout.ts`. Сейчас она возвращает `unavailable`, и сайт показывает окно «Оплата скоро заработает». С сервером функция должна создать заказ и счёт в Kaspi и вернуть `{ status: "redirect", url }`; письмо с АВР тогда отправляет сервер.

## Что входит в описание архетипа

Для каждого из 12 архетипов на двух языках: ключевые слова, дар, теневая стратегия, слепая зона, скрытые риски, что человеку нужно, что его выматывает, роль в команде, поведение в конфликте, возможные истоки в детском опыте (подаются как гипотезы), диагноз по трём зонам зрелости, два шага развития, три практических инструмента, три суперсилы, проявления в работе, семье, дружбе и в отношении к себе, три книги и план на 30 дней по неделям. Книги указаны по русским изданиям и на казахском не переводятся.

Все тексты авторские. Методика не использует названия, описания или статистику чужих тестов.

## Языки

Русский и казахский переключаются кнопками RU / ҚАЗ на стартовом экране и в результатах. Выбор запоминается в браузере, по умолчанию берётся язык браузера. В Unbounded нет казахских букв (Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ), поэтому для казахского заголовки набираются Montserrat.

Казахские тексты стоит вычитать носителю языка перед запуском.

## Алгоритм

1. **ТОП-3.** 36 дилемм, в каждой выбор из двух карт, на ответ 21 секунда (таймер только подсказывает). Пары подобраны так, что каждая из 12 карт встречается ровно 6 раз, и подряд не идут вопросы с общей картой. Голоса суммируются. Если на границе третьего места ничья, показывается уточняющий вопрос. Он повторяется, пока все три места не будут определены.
2. **Этап 2.** 15 утверждений о зрелости (по 5 на каждую из ТОП-3: три теневых и два опорных) и 3 контрольных вопроса, перемешанные между собой. Утверждения одной карты не идут подряд.
3. **Индекс зрелости.** Исходная формула `MI = grounded·2 / ((shadow_1 + shadow_2) + grounded·2) · 100%` записана через средние: `MI = ḡ / (s̄ + ḡ) · 100%`, где s̄ среднее по теневым утверждениям, ḡ среднее по опорным. Для набора «два теневых, одно опорное» это ровно исходная формула. Зоны: красная до 35%, жёлтая 36–70%, зелёная от 71% (по округлённому значению).
4. **Валидность.** Если хотя бы на 2 контрольных вопроса дан ответ 1 («Никогда»), включается `defense_flag`: индекс валидности снижается до 50%, MI ограничивается потолком 65%, на экране результатов показывается предупреждение.
   Дополнительные проверки качества ответов (снижают индекс валидности, но не меняют MI):
   - одинаковый ответ на все 15 утверждений о зрелости: минус 25 пунктов;
   - половина утверждений Этапа 2 отвечена быстрее 1,5 с: минус 20 пунктов.

5. **Тип самооценки** (по среднему MI ТОП-3):
   - ≥71%: опорная безусловная;
   - 61–70%: формирующаяся опора (промежуточный тип: спецификация этот диапазон не покрывает);
   - ≤60%: логическая условная, если среди ТОП-3 по сумме голосов перевешивают ARCH_01/02/04/12, эмоциональная условная, если ARCH_07/08/09/11, иначе смешанная условная.

**Против социально желательных ответов.** Этап 1 устроен как вынужденный выбор между двумя одинаково привлекательными вариантами, поэтому «хорошего» ответа там нет. В Этапе 2 все утверждения, включая контрольные, отвечаются по одной поведенческой шкале частоты («Никогда … Почти всегда»), так что контрольные вопросы не выделяются. Под каждым утверждением показывается подсказка, которая нормализует теневые проявления.

**Вовлечённость.** После 12 и 24 дилемм показывается промежуточный инсайт о лидирующем архетипе, а в шапке видно оставшееся время.

Экспорт: настоящий A4 PDF на 10 страниц (обложка, три карты и тип самооценки, радар и «зачем это», по две страницы на каждую карту, план на 30 дней и книги), картинка для сторис 1080×1920 и копирование текста. PDF собирается в браузере через `@react-pdf/renderer` (`src/lib/pdf/`): библиотека и шрифты грузятся только при первом нажатии кнопки. В PDF берутся полные TTF из `@expo-google-fonts` (куски `@fontsource` библиотека не склеивает), для казахского заголовки набираются Montserrat.

**Оформление.** Стиль «колоды карт»: кремовые карты с чёрной обводкой и жёсткой тенью, шрифты Unbounded и Onest, у каждого архетипа свой знак (`src/data/glyphs.ts`). Цвет фона переключается на стартовом экране и в результатах (`src/lib/theme.ts`) и запоминается в браузере.
